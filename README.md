# upbit_automation_backup

이 저장소는 비트코인 스윙 트레이딩 자동화를 위한 예제 코드와 설정을 포함합니다.

## 필요 패키지
- python-dotenv
- pyupbit
- pandas
- numpy
- openai
- python-telegram-bot
- requests
- ta

## 실행 방법
1. 위 패키지들을 `pip`으로 설치합니다.
2. `.env` 파일에 Upbit, OpenAI, Telegram API 키 등을 설정합니다.
3. `python trade_gpt40.py` 명령으로 스크립트를 실행합니다.
